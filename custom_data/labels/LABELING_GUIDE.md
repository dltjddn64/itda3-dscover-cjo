# 라벨링 가이드라인

팀원이 라벨링을 나눠서 할 때 형식을 맞추기 위한 문서입니다. (배경: `ITDA_500_image_date_candidates.csv`가 사람마다 표기가 달라서 42/500장이 자동으로 안 풀렸음 — 이 문서대로만 적으면 그런 손실을 줄일 수 있습니다.)

## 왜 라벨링하나
1. 파이프라인이 실제로 얼마나 맞히는지 측정하는 기준(검증셋)
2. 대회 가산점(최대 5점) — "직접 수집·라벨링하여 모델을 확정한 팀"에 해당. 요약서 PDF에 라벨링 → 발견한 문제 → 개선 수치를 증빙으로 써야 함

## 파일 형식
CSV, 컬럼: `image_id, filename, date_candidates_raw`
- `image_id`: 파일명 숫자부분 그대로 (예: `000009`, 앞자리 0 유지)
- `date_candidates_raw`: 사진에서 보이는 날짜를 **원본 그대로** 적기 (아래 규칙만 지키면 형식은 자유)

## 반드시 지켜야 하는 것 (안 지키면 자동 파싱 불가)

1. **연도는 꼭 4자리 또는 2자리로 포함**해서 적기.
   - ❌ `10.14` (연도 없음 → 복원 불가, 무조건 수동 확인行)
   - ✅ `2026.10.14` 또는 `26.10.14`
2. **날짜가 사진에 여러 개 보이면 전부 다 `|`로 구분해서 적기** (어떤 게 정답인지 우리가 몰라도 됨, 규칙으로 나중에 자동 판별함)
   - 예: `2025.09.10 | 2026.06.09` (부터/까지 둘 다 적어도 OK — 늦은 날짜를 자동으로 채택함)
3. **날짜를 아예 못 찾겠으면 빈칸 대신 명확하게 표시**
   - 빈칸(`""`)은 "정말 아무 날짜도 안 보임"이라는 뜻으로 처리됨. 애매해서 못 정한 거면 `UNSURE` 같은 걸로 구분해서 적어주세요 (빈칸과 구분 필요).
4. 구분자(점/슬래시/대시/공백)는 아무거나 써도 됩니다. `2026.10.14`, `2026/10/14`, `2026-10-14`, `2026 10 14` 다 지원.
5. 일-월-연도 순서(수입 상품, 유럽식 `22.06.2021`)도 지원되니 그냥 보이는 대로 적으면 됩니다. 순서 신경 안 써도 됩니다.
6. 영문 월 이름(`MAY 12 2026`, `07FEB2022`)도 지원됩니다.

## 소비기한 판별 우선순위 (라벨링할 때 참고)
사진에 날짜가 여러 개 있을 때 뭐가 "정답"인지 헷갈리면 이 순서로 판단:
1. **"유통기한" / "소비기한" / "까지"** 라는 글자 바로 옆에 있는 날짜 → 이게 정답
2. **"제조일자" / "생산일자" / "소분일" / "포장일" / "부터"** 옆에 있는 날짜 → 정답 아님 (다른 종류)
3. 둘 다 안 보이고 날짜만 여러 개 있으면 → **가장 늦은(미래) 날짜**가 정답일 확률이 높음 (소비기한은 항상 제조일보다 미래)
4. 그래도 모르겠으면 → 다 적어놓고 `UNSURE` 메모 남기기 (우리가 나중에 규칙으로 판별하거나 직접 확인)

## 파서가 아직 처리 못 하는 것 (이런 경우는 자동 해결 안 되니 참고만)
- 연도 없이 월.일만 있는 경우 (`10.14`)
- 월/연도만 있고 일자가 없는 경우 (`2026.01`, `OCT.2021`) — 이런 경우 "해당 월 1일"로 임의 추정하지 말고 원본 그대로 적어주세요, 저희가 따로 처리합니다
- 완전히 붙여쓴 월이름+숫자 (`AUG292020`처럼 구분자 하나도 없는 경우) — 가능하면 `AUG 29 2020`처럼 한 칸씩 띄어서 적어주세요
